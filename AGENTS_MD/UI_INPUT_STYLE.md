# Правило ввода данных

Новые записи создаются и проверяются в редактируемой таблице: «Добавить строку» → заполнить ячейки → «Сохранить». Ошибки показываются в строке, а не только общим сообщением. Отдельные поля ввода рядом с таблицей для создания той же сущности не используем.

Для действий над существующими записями выбираем строку в таблице; дополнительные параметры действия (например, фактическую дату) редактируем в её ячейке. После сохранения перечитываем данные, не удаляя строки, которые не удалось сохранить.
